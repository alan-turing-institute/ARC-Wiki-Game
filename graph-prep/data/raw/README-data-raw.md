# Data Raw

This folder contains the raw files from the Wikipedia dumps. These files have been downloaded from the 2024-07-20 dump, which was the latest stable dump at the time of writing.
[We Used This Mirror](https://mirror.accum.se/mirror/wikimedia.org/dumps/enwiki/20240720/)

The OpenAlex snapshot can also be contained here which is available from an S3 bucket.
[OpenAlex Snapshot Information](https://docs.openalex.org/download-all-data/openalex-snapshot)
